Yellow Code — version history
==============================

v7  (current)
  - Payment information now shows on the CUSTOMER-facing invoice
    (public link /invoice/..., print page, PDF): payment status badge
    (Paid / Partially paid / Overdue / Unpaid), Total / Paid / Amount due
    rows, and the full "Payments received" history table.
  - Amount due on the customer invoice now becomes 0.00 after full payment.
  - Admin sidebar footer shows the version number (v7) so you can always
    verify which build is running.

v6
  - Payments: record/delete payments with method (cash, bank, cheque,
    mobile banking, card, other); invoice status auto-recalculates
    (ISSUED -> PARTIAL -> PAID).
  - Reports module (sidebar > Insights > Reports): Sales, Receivables
    (AR aging from due date), Collections, Products, Customer statement,
    Pipeline — each with filters and CSV export.
  - Sidebar global search (customers, products, quotes, orders, invoices).
  - 100% mobile/tablet responsive admin (sales order pages included).
  - "Public site URL" in Admin > Company profile: customer invoice links
    use your real domain instead of localhost.

v5
  - Base release used before v6.
